# Использование WinGPT TTS

В терминале: `list` → `show 12` → `say` (или сразу `say 12`). `next` и `prev`
меняют выбор, `last` выбирает последний ответ. `read` обновляет этот же список
сообщениями, загруженными сейчас в чате: напечатанные номера сразу работают в
`show` и `say`. При наличии перекрытия новые сообщения дополняют сохранённую
историю, а её старые номера сохраняются. Последний прочитанный завершённый ответ
выбирается автоматически, поэтому после `read` можно сразу ввести `say`.
Если снимки не удалось связать или открыт другой чат, выбирается доступный
фрагмент; старые полные импорты остаются в отдельных файлах.

Значок запуска в виджете озвучивает
выбранное сообщение. До первого импорта он пробует выбрать последний завершённый
ответ, доступный в открытом чате. Во время подготовки голосового файла GIF стоит,
во время воспроизведения двигается. Значок паузы сразу выключает звук, очищает
очередь и отменяет только созданную этой программой задачу Applio. Значки появляются
при наведении внутри портрета. Виджет с металлической рамкой; его можно перетаскивать за портрет и
масштабировать колёсиком (50–300%) или через `set size 150`. Размер запоминается.
Правой кнопкой открывается меню оформления и выхода; также можно выйти через `quit`.

Портрет и рамка — единое оформление. Оно включает путь к GIF или статичному
изображению, стиль, цвет и толщину рамки. Рамка находится снаружи изображения,
поэтому не обрезает портрет; размер меняется у них вместе. Анимация и кнопки
озвучки работают как раньше. Значок в панели задач использует тот же портрет с рамкой.

В меню правой кнопки можно выбрать портрет, цвет и толщину рамки, переключить
оформление и сохранить свой пресет. Встроены `classic` (сталь со скосами, как
у игровых портретов), `frost` (холодная сталь), `minimal` (тонкий кант) и `bare`
(без рамки). Изменения применяются сразу и сохраняются после перезапуска.
Пресет хранит **картинку вместе с рамкой**, поэтому можно собрать несколько персонажей.

То же через терминал:

```text
preset frost
set border-width 9
set border-color "#92999c"
set image "assets/arthas.gif"
preset save "Мой Артас"
preset classic
preset "Мой Артас"
```

`preset` без аргументов показывает список. Толщина — от 0 до 30 пикселей при
масштабе 100%; `set border-style bevel`, `flat` или `none` меняет стиль.
Относительные пути к портретам считаются от папки проекта; абсолютные тоже работают.
Существующие настройки GIF, громкости, размера и озвучки сохраняются при обновлении.

`set volume 50` устанавливает громкость озвучки на 50%, `set volume 0` выключает
звук, `set volume 100` возвращает исходную громкость. Изменение действует сразу,
включая текущую запись и очередь, и сохраняется после перезапуска. Громкость
других программ и настройки звука Windows не меняются. Повторная генерация
звукового файла не требуется.

`auto on` включает чтение **новых завершённых** ответов. Старые ответы при
включении режима не проигрываются. Если включить его во время генерации,
программа дождётся окончания текущего ответа. В авто-режиме «Стоп» ставит
наблюдение на паузу, «Старт» возобновляет ожидание новых ответов. `auto off`
возвращает ручной режим; для немедленного выключения текущего звука используй `stop`.

В авто-режиме держи открытый чат прокрученным к концу. Программа сама его
не прокручивает и не читает другие открытые чаты. При переключении на другой чат
его существующие ответы становятся исходной точкой наблюдения. Из-за виртуализации
старые сообщения выше текущей области недоступны для фонового чтения. Если ответ
появился, пока чат был свёрнут или закрыт, автоматическая озвучка не гарантируется;
для ручного выбора обнови список через `read` или всю историю через `scan`.
Статус наблюдения виден в `status`.

Автоозвучка ждёт конца генерации и затем неизменности текста в течение 2.5 секунд.
Интервал проверки — 1.5 секунды. Это отдельные настройки `stable` и `poll`;
`delay` по-прежнему относится только к прокрутке при полном чтении.

Только терминал, без виджета:

```powershell
.\wgtts --no-widget
```

Открой нужный чат в приложении ChatGPT и введи `scan`. Во время прохода приложение
прокручивает область переписки от начала к концу и затем восстанавливает исходный
процент прокрутки. Подожди окончания сбора; `Ctrl+C` завершает программу, прерывает
сбор, сохраняет прочитанную часть и восстанавливает прокрутку.

Команды терминала:

| Команда | Действие |
| --- | --- |
| `scan` | Прочитать и сохранить историю открытого чата |
| `read` | Обновить общий список доступными сейчас сообщениями |
| `list` | Текущий список с теми же номерами для `show` и `say` |
| `show 12` | Показать двенадцатое сообщение целиком |
| `next`, `prev` | Переключить выбранное сообщение |
| `last` | Выбрать последний ответ ассистента |
| `say`, `say 12` | Озвучить выбранное сообщение / сообщение №12 |
| `start`, `stop` | Запуск / остановка, также доступны кнопками виджета |
| `auto on`, `auto off` | Автоозвучка новых ответов / ручной режим |
| `applio` | Заново взять рабочие TTS-настройки из Applio |
| `settings` | Посмотреть настройки голоса и чтения |
| `status` | Посмотреть полноту истории и текущий выбор |
| `set delay 0.5` | Изменить задержку чтения после прокрутки |
| `set rate 20`, `set pitch -10` | Скорость речи / сдвиг тона |
| `set volume 50` | Громкость озвучки, 0–100%, включая текущую запись |
| `set size 150` | Размер виджета, 50–300% |
| `preset`, `preset frost` | Список оформлений / применить пресет |
| `preset save "Мой Артас"` | Сохранить портрет и рамку вместе |
| `set image "assets/arthas.gif"` | Изменить портрет (GIF или статичное изображение) |
| `set border-width 9`, `set border-color "#92999c"` | Толщина / цвет рамки |
| `set border-style bevel` | Рамка: `bevel`, `flat`, `none` |
| `set voice ru-RU-SvetlanaNeural` | Выбрать голос TTS |
| `set poll 1.5`, `set stable 2.5` | Интервал проверки / ожидание стабильного ответа |
| `set model "logs/…/model.pth"`, `set index "logs/…/model.index"` | Модель / индекс, пути относительно среды Applio |
| `set url http://127.0.0.1:8000` | Адрес локального Applio Desktop API |
| `help`, `quit` | Справка и выход |

Команду можно выполнить и без интерактивного режима:

```powershell
.\wgtts scan
.\wgtts list
.\wgtts show 12
```

Результаты сохраняются локально в `data/history/`: обновляемый `chat-*.json`
для каждого чата, `full-*.json` с его последней подтверждённой полной историей
и один `latest.json` для открытия после перезапуска. Каждый новый ответ обновляет
существующие файлы, а не добавляет полную копию растущей переписки. Объём хранения
растёт вместе с самим текстом, без суммы всех промежуточных версий.
Одинаковые названия чатов не являются основанием для их объединения.
Файлы истории исключены из Git через `.gitignore`.

## Как работает чтение

Приложение виртуализирует историю: UIA видит лишь загруженную часть переписки.
Сборщик прокручивает чат небольшими шагами и соединяет перекрывающиеся снимки
в порядке сообщений. Повторы текста в разных сообщениях сохраняются. При разрыве
между снимками шаг уменьшается; если связать их не удалось, результат помечается
неполным. Скрытые элементы напрямую через ItemContainer в проверенной версии
приложения недоступны.

Содержимое читается через TextPattern, поэтому сохраняются пробелы, абзацы, списки
и код. Таблицы восстанавливаются по ячейкам GridPattern, а если он недоступен —
по строкам и ячейкам дерева доступности. В истории и `show` они сохраняются как
Markdown-таблицы с заголовками и пустыми ячейками. Переносы внутри ячейки обозначаются
`<br>`. При озвучке каждая строка читается с названиями колонок, например:
«Строка 1. Товар: чай; Цена: 50; Примечание: пусто». Код в блоках не преобразуется
в таблицы. Таблицы без заголовков получают названия «Столбец 1», «Столбец 2».
Чтобы заново извлечь таблицы из уже сохранённых сообщений, выполни `read` в нужной
области чата или `scan` для всей истории; потерянные границы ячеек из старого
сплошного текста восстановить нельзя.

Подписи авторов проверяются по роли заголовка и служебному классу, а не
только по тексту: цитата «ChatGPT сказал:» не начинает новое сообщение. Настоящие
кнопки копирования и озвучки исключаются по их диапазонам; такие слова внутри
сообщения остаются. Исходный учебный скрипт сохранён в `tools/legacy/prototype.py`.

Полнота подтверждается только после достижения обоих концов, соединения всех
снимков и совпадения числа сообщений пользователя с навигацией приложения.
Если счётчика нет, возникла ошибка, чат переключился или ответ ещё генерируется,
программа сообщает о неполноте. Это текст интерфейса текущей ветки; содержимое
прикреплённых файлов отдельно не загружается. Изменения интерфейса ChatGPT могут
потребовать обновления извлекателя.

## Озвучка и файлы

Используется REST API установленного Applio Desktop (`/api/tts`, `/api/jobs`,
`/api/audio/raw`), по умолчанию `http://127.0.0.1:8000`. Gradio не требуется.
Applio создаёт TTS-аудио через Edge TTS, затем применяет твою модель RVC.
Для Edge TTS нужен интернет: текст выбранного ответа отправляется сервису TTS.
Преобразование голосом Артаса выполняется в Applio на этом компьютере.

Настройки сохраняются в `data/settings.json` и применяются к следующим задачам.
Последний готовый WAV в `data/audio/` сохраняется после проигрывания, Stop,
ошибки воспроизведения и выхода. Повторный запуск того же текста с теми же
настройками голоса использует этот файл, в том числе после перезапуска программы.
Громкость меняется без новой генерации.
Предыдущая запись удаляется только после успешной новой генерации. Если новая
генерация завершилась ошибкой или была отменена, предыдущая запись остаётся.
Запоздалый результат отменённой задачи удаляется и не заменяет готовую запись.
`last-recording.json` хранит имя WAV и отпечаток текста и настроек для повторного
воспроизведения. Посторонние файлы программа не удаляет.
После скачивания удаляются также исходный TTS и преобразованный WAV этой задачи
в Applio — только явно возвращённые API пути с именами генерируемых файлов внутри
`assets/audios`. Модели и чужие задачи не затрагиваются. Для отменённых задач
удаляются только файлы, которые Applio успел указать в ответе API.
Старые аудиофайлы и архивы, созданные до обновления, автоматически не очищаются.
Встроенный GIF лежит в `src/wgtts/assets/arthas.gif`; путь `assets/arthas.gif` в настройках остаётся его переносимым обозначением.
Настройки самого Applio программа не меняет. Авто-режим после перезапуска
нужно включать снова. Завершённые ответы, обнаруженные в авто-режиме, сохраняются
в истории; если полной истории ещё нет, это частичный снимок. Частичный снимок
не перезаписывает `full-*.json` с последней подтверждённой полной историей.
