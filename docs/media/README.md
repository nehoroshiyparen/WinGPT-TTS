# Медиа для README

Демонстрация собрана из настоящих ресурсов WGTTS и одного короткого WAV
из локальной папки `data/audio`. Оригинал остаётся на месте.

| Файл | Содержимое |
| --- | --- |
| `player-demo.gif` | Современная карточка: ожидание, разговор и плавное раскрытие плеера |
| `player.png` | Чёткое сравнение свёрнутого и раскрытого плеера |
| `hero.gif` | Цикл анимации портрета в рамке `classic`, без звука |
| `frames.png` | Галерея классических рамок; полная пересборка добавляет все текущие пресеты |
| `voice-poster.png` | Обложка звукового демо с волной из выбранной записи |
| `voice-demo.mp4` | Портрет с анимацией и голосовым примером, 7,28 с, H.264 + AAC |
| `voice-sample.mp3` | Та же запись в компактном аудиоформате |
| `voice-sample.wav` | Исходная запись, скопированная без изменения звука |

Портрет в видео использует штатный цикл анимации виджета.
Остальные файлы из `data/` не входят в демонстрацию.

## Пересборка

Из корня проекта, в установленном окружении:

Только новый интерфейс, без пересоздания голосовых примеров:

```powershell
python -m tools.render_readme --ui-only
```

Полная пересборка, включая прежний пример с голосом:

```powershell
python -m pip install -e ".[media]"
python -m tools.render_readme
```

Генератор по умолчанию использует сохранённый `voice-sample.wav`.
Другую запись можно передать явно:

```powershell
python -m tools.render_readme --audio "путь/к/примеру.wav"
```

Картинки и анимация отрисовываются тем же `Portrait`, что и живой виджет.
Новый плеер использует штатные `TransportLayout`, `DrawerMotion` и изображения кнопок;
для иллюстрации показана запись с позицией 0:42 из 2:10.
Для видео и MP3 применяется FFmpeg из необязательной зависимости `imageio-ffmpeg`.
Шрифты берутся из системных Segoe UI или DejaVu Sans.

## Форматы в README

GIF содержит только анимацию. Голос сохранён отдельными MP3 и WAV,
а также аудиодорожкой AAC в MP4. В README используются относительные ссылки
на эти файлы; поведение предпросмотра зависит от места просмотра README.
